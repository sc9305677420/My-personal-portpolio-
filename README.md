Shiva Chaudhary Portfolio is a single-page personal portfolio website designed to showcase academic background, technical skills, and projects for internship and job opportunities. The site is built with pure HTML5, CSS3, and vanilla JavaScript — no frameworks — keeping it lightweight, fast-loading, and easy to host on any free static hosting platform.
Key features:
Clean, light professional theme with smooth scroll-reveal animations and a reading-progress bar
Fully responsive layout — works across desktop, tablet, and mobile
Sections for story/timeline, technical skills (with animated progress bars), featured projects, education, and contact
Functional contact form that opens the visitor's email client
SEO-ready: optimized meta tags, Open Graph & Twitter Card previews, JSON-LD structured data (Person schema), sitemap.xml and robots.txt for search engine indexing
Custom hero section with a photo card featuring gradient overlay for text readability
Tech stack: HTML5, CSS3 (Grid & Flexbox), JavaScript (DOM, IntersectionObserver for animations)
